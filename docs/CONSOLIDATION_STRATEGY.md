# Consolidation phase — v1.8

Temporary major-feature freeze: improve beginner clarity, adaptive Practice, natural Spanish, content governance, maintainability, visual/accessibility QA and offline reliability before expanding breadth. A1.1–B2.2 and the eleven existing Practice activities are the ceiling. An empty roadmap slot is not permission to add another feature.

Home suggests the next useful action; Learn teaches; Practice reinforces; Review schedules retrieval; Profile holds vocabulary, references and data controls. Preserve Home / Learn / Practice / Review / Profile and the historical internal Games route. Beginners see a recommendation and familiar choices before deliberately opening the full catalogue. Established learners retain direct access. Recommendations explain real error evidence and use reached sources; inactivity suggests practice, never proves weakness.

There is no participant recruitment, formal external beginner study, KPI/OKR programme, retention target or management dashboard in this release. Local beta diagnostics are optional technical evidence, not a product-success framework.

Do not broaden content until independent language review, actual learner observation and physical-device/accessibility testing have informed the next priorities. Automated gates are necessary but cannot supply those judgements.
