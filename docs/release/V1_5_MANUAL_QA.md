# v1.5 manual QA checklist

Use an exported backup and a disposable test profile. Browser checks simulate viewport/insets; separately test real Samsung devices. No new Pixel/Gboard profile is part of this release.

- **Home:** fresh beginner, established learner, due review and empty review. Continue is first; advanced practice is disclosed and all tools remain reachable.
- **Learn:** current unit first, completed unit, all-unit revision, stage changes and stage boundary. Expand activities and useful phrases; the next action must preserve the required path/checkpoint.
- **Lessons:** correct/incorrect feedback, brief explanation/Why, controlled construction, listening transcript gate, open writing/revision, Enter/Go, lesson completion, Continue and Finish for now. Bull for checkpoint/recovery; ordinary success is compact.
- **Games:** both cards visible on a normal S24 portrait; one column at 320px and large text. Shared default level, intentional advanced warning, Conjugations ten questions, Verb Tables three tables, advanced settings, saved checked/unchecked game resume, native Back.
- **Vocabulary:** both search directions; to know → saber/conocer; accentless café; año versus ano; unknown query; noun gender/examples; senses/region notes; Hear, Save/Remove, More popup, Back/Escape/outside dismissal. Search while keyboard/composition is active. Saved Words search/filter/remove still works.
- **Profile/data:** level/streak, actual progress, capabilities, recommendations, period statistics; lower placement/data sections. Export/import an older backup. Never uninstall without checking the backup/signing-key situation.
- **Answer reports:** wrong controlled response and unverified guided response. Reporting changes no score/review/mastery; duplicate tap is safe. Export browser and Android JSON, inspect IDs/response/model and share only deliberately. Importing a report as progress must reject without replacing valid data.
- **Review:** Due Today, Weak Areas, Past Mistakes, no items, corrected items, due dates and mixed Today’s Review. New-story success must not clear a different older passage snapshot.
- **Stories:** practical, social, chaos, optional prediction, modern-message format, B-level multiple perspectives, glossary, inferred joke and standalone callback. Verify the five permanent questions, message construction, reading context on review and interrupted resume. Compare against STORY_BIBLE.md.
- **Support:** Spanish-first notice dismisses once and survives import; English help translates the actual question. Dictionary tip disappears after acknowledgement/use or its limited exposure. Neither is a learning hint.
- **Primer:** all seven sections, normal es-ES synthetic playback, navigation cancels speech. No microphone prompt or pronunciation grade.
- **Responsive:** S22/S24/S25-sized portrait/landscape, light/dark, gesture/three-button, cutouts/insets, keyboard open/closed and large text. Scroll every final control above system/app navigation; inspect long answers, dictionary popups, story paragraphs and game cards.

External educator/native-speaker review should check narrative naturalness, register, supported inference, plausible distractors, readability and cultural tone. Do not mark these performed merely because automated tests pass.
