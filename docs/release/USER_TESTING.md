# Full-course user-testing checklist

Use this checklist before wider distribution. Record device/Android version, navigation mode, app version, offline voice, text size, stage/start path and the exact permanent item ID. This release has automated validation; it has not received physical-device, acoustic or independent Spanish educator validation.

Export and verify a backup before upgrading. Preserve the signing key; a fresh CI debug key can prevent an in-place upgrade. Do not uninstall a learner’s app before recovering a tested backup.

| Check | Deliberate test and expected behaviour |
| --- | --- |
| 1. Onboarding | Fresh offline install; start normally without account/network. |
| 2. Placement | Try low/high results; recommendation is provisional, never certification; earlier foundations are assumed, not fake completions. |
| 3. A1.1 | Greetings/café/time: recognition, retrieval, story and checkpoint; existing saved progress remains. |
| 4. A1.2 | Preferences/plans/routines: connected responses and reflexives; revisit earlier material without changing the starting path. |
| 5. A2.1 | Recent/perfect versus finished events, travel and health; verify preserved stories/IDs. |
| 6. A2.2 | Background/event contrast, routine problems and connected messages; no lost completion history. |
| 7. B1.1 | Narrate an interruption, explain a change and offer advice. Assess pacing beyond A2. |
| 8. B1.2 | Misunderstanding, application, recommendations and wishes; check limited subjunctive scaffolding. |
| 9. B2.1 | Distinguish evidence/cause, register, chronology and real versus imagined conditions. |
| 10. B2.2 | Compare perspectives, counterargument, faithful reporting and final project. Check useful complexity rather than obscure vocabulary. |
| 11. Controlled Writing | Correct target/variant succeeds; incorrect target fails with teaching feedback. Do not accept missing negation or ano for año. |
| 12. Guided Writing | Submit a natural unexpected formulation. It should survive as uncertainty/model comparison, not an automatic failure. |
| 13. Free Writing | Submit an independent paragraph. No claim that all grammar is correct; comparison/reflection is required. |
| 14. Correct alternatives | Change word order, name phrase or permitted regional/formal form. Report any confident false rejection with exact prompt/response. |
| 15. Near miss | Submit one/two changed letters in a controlled model. Feedback should describe a limited comparison, not pretend dictionary diagnosis. |
| 16. Verb diagnostics | Try yo habla, nosotros come, vosotros tienen; explicitly requested tense errors should identify the known form/person. |
| 17. Uncertainty | Submit a valid response beyond authored rules, incomplete message or unrelated response. Unknown meaning should not receive a confident grammatical pass. |
| 18. Why? | Open explanation; verify the identified issue is correct, concise and appropriate to the stage. |
| 19. Listening | Install local es-ES voice; test audible .75×/1×, delayed start, failure/skip, replay, transcript reveal and Back cancellation. A successful bridge call alone does not prove sound. |
| 20. Speaking | Attempt before model, hear it, select Got/Needs practice. No microphone request, recording, ASR or pronunciation score. |
| 21. Conjugations | Ten varied unique contexts; each wrong blank explains the selected form and the right pattern. No noun/connector is mistaken for a conjugated verb. |
| 22. Tables | Six Spain-first persons, ordinary three tables; typed/selectable practice and 3/5/10/15/20 counts. |
| 23. Table randomisation | Repeat rounds: varied targets/cells/options. Full blank tables require spaced unassisted evidence, not repeated clicks. |
| 24. Weak Areas | Repeated errors/hints surface meaningful labels; focused practice stays eligible. |
| 25. Today’s Review | Due errors plus eligible weak targets; no duplicates or invented queue. Unknown writing reflections are not verified SRS corrections. |
| 26. Level switching | Independently select grammar ceilings up to B2.2, then lower them. Preserve higher saved attempts and all main-course progress. |
| 27. Import/export | Browser and Android export; import old v1/v2 and fresh writing/game saves. Invalid imports must not overwrite valid progress. |
| 28. Resume | Leave before comparison, after model, after revision and after reflection. Background/kill/reopen: preserve questions, passage, response, hint and current index. |
| 29. Android Back | Lesson saves; game/table/focused practice returns safely; main tabs → Home; Home backgrounds. |
| 30. Keyboard | Go checks short controlled answers once. Multiline Enter adds a newline; primary controls remain reachable. Test Samsung IME and physical keyboard. |
| 31. Large text | 320px/narrow and S24-class width, Android large text, portrait/landscape. No horizontal table/story overflow. |
| 32. Dark mode | Navy/coral/teal, choices, feedback, requirements and disabled controls remain legible; icon remains bull face. |
| 33. Long passages | Read full B2 story, glossary and reread during review; final button scrolls above app/system navigation. |
| 34. Long writing | Several paragraphs, accented characters, ñ and HTML-like text; safe display, revision, model/Why, resume and no unintended keyboard submission. |
| 35. B2 milestone | Complete the actual required path; show actual completion counts, assumed foundations, capabilities and review maintenance. No CEFR certification or C1/C2 continuation. |

For writing tests deliberately include valid unexpected Spanish, alternate word orders, spelling mistakes, wrong-person conjugations, missing information, negation and off-task responses. Include quoted examples of an error (for example “Ella dijo: «Mi llamo Ana», pero luego corrigió la frase”) and proper nouns. Track **false acceptance and false rejection separately**; absence of a detected error is not a grammatical pass.

Ask a Spanish educator/native speaker to review all B unit models, glossaries, inference support, register, distractors, feedback and naturalness, then have real learners attempt a short path in each stage without coaching. Record where instructions or difficulty are unclear. Freeze expansion during this test period; do not start C1/C2.
