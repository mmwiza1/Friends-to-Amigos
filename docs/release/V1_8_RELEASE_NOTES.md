# Friends to Amigos v1.8.0

A consolidation release for the existing A1.1–B2.2 course: clearer beginner support, calmer Practice choices, targeted reinforcement and better content/release governance. The eleven existing activities remain; no new course level or major game was added.

## Download the application

For a GitHub Release with an APK attached, download the Android APK under **Assets**. CI also produces a debug test APK; it is not a claim of physical-device validation.

## Installation and first launch

Learner progress remains schema v2, with the same storage key, IDs, active snapshots, reviews and Saved Words. Export a backup before switching installations. If debug signing differs and Android requires an uninstall, keep that backup before uninstalling. No account, microphone permission or cloud service is required.

## New in v1.8.0

### Beginner clarity and Practice

- Additional meaning-first examples introduce the first construction tasks in seven later A1.1 units. Final outcomes, later retrieval/transfer and all checkpoints remain.
- Early Practice emphasises a recommendation and familiar activities; the complete eleven-activity catalogue opens deliberately. Established learners retain the full catalogue.
- Real weakness recommendations explain recorded errors and open related reached material. Home offers a direct weak-area action.

### Spanish and stories

- Surgical word-order, music-film, temporal viewpoint and explicit-referent corrections improve A1.2/A2/B-level models.
- Six A1.1 story glossaries now support expressions actually in the episode. A reported-past clause has a short English glossary explanation.
- Spain-first transport preferences and valid tomar alternatives remain; historical saved questions/passages are not rewritten.

### Privacy and maintainability

- Optional beta diagnostics remain on-device, bounded and exportable/resettable under Profile data controls. No learner name, answer/writing text, audio, device ID, third-party tracker or automatic upload is collected.
- A language audit separates definite structural errors from editorial flags. Content-review policy, an incremental canonical starter registry and manual visual/accessibility checklists improve future maintenance.
- The existing screenshot release gate remains required: version, UI fingerprint, image integrity and recorded visual review must agree.

### Bug fixes

- Corrected stale glossary entries and unnatural published model wording without changing activity order or stable identities.
- Recommendation-driven grammar practice checks reached sources even when a higher manual grammar level was previously selected.

## Known issues and limitations

Automated audits and agent editorial/visual inspection are not independent native-speaker/educator approval. Actual beginner observation and physical-device/TalkBack testing remain necessary. No formal external usability-study programme, KPI/OKR framework, CEFR certification, arbitrary prose grader or pronunciation assessment was added. External recommendations still depend on provider access when opened; the core app remains offline.
