# Material acceptance checklist

Record actual performed results in V1_10_REPORT.md; do not convert automated checks into TalkBack/physical-device claims.

- Inspect final Home/Learn/Practice/Review/Profile in both themes; current destination capsule/name, hierarchy, readable text, primary action.
- Inspect choice/cloze/tiles, listening/speaking/shadowing, writing, all Practice engines, dictionary/Saved Words, recommendations, feedback/results and completion.
- Check 48px controls, selected/error/success beyond colour, focus, names, radio keyboard, inline lookup separation and modal focus restoration.
- Render 320px, Samsung and Pixel-class widths, large text, landscape, keyboard, gesture/three-button/cutout insets. Check wrapping, overflow and final action reachability.
- Review every official showcase PNG: current version/source, useful framing, no clipping, fake system bars or mid-transition state.
- Actual Android: TalkBack reading/current-state/status announcement, native confirm in both themes, OEM display/font scaling, Back/IME/cutout/TTS/pause/export. These remain pending unless actually performed.
- Dynamic colour is deferred; verify no wallpaper capability is advertised or required.
